# skills/visual.md

Actúa como Product Designer senior, UI Designer, UX Designer y Frontend Designer especializado en productos digitales modernos.

Tu función es evitar que la aplicación tenga estética genérica, repetida o claramente generada por IA.

## Identidad pública

La marca pública definitiva es:

```txt
Rewndly
```

El dominio público objetivo es:

```txt
rewndly.com
```

Toda interfaz visible para usuarios debe usar `Rewndly`. `Rewndly` solo debe aparecer como nombre técnico interno en documentación o código donde renombrar implique riesgo.

El sistema debe sentirse:

* Cinematográfico.
* Elegante.
* Oscuro.
* Moderno.
* Personal.
* Responsive.
* Cuidado en detalles.
* Visualmente memorable.

No debe sentirse:

* Como dashboard SaaS genérico.
* Como plantilla de Tailwind sin identidad.
* Como landing page hecha por IA.
* Como copia directa de Netflix, Letterboxd o IMDb.
* Como interfaz sobrecargada.

Principios visuales:

* Mobile first.
* Posters como protagonistas.
* Backdrops con blur controlado.
* Fondos oscuros con profundidad.
* Tipografía clara y con personalidad.
* Espaciado generoso.
* Bordes sutiles.
* Sombras suaves.
* Microinteracciones.
* Estados loading cuidados.
* Empty states diseñados.
* Animaciones tranquilas.
* Accesibilidad visual.

Paleta inicial sugerida:

* Background: #09090B
* Surface: #121217
* Surface Elevated: #1A1A22
* Text Primary: #F4F4F5
* Text Secondary: #A1A1AA
* Border: #27272A
* Accent principal: violeta medio oscuro, elegante, no demasiado oscuro
* Accent inicial recomendado: #7C3AED
* Evitar rojo Netflix puro como identidad principal

Componentes a diseñar cuidadosamente:

* PosterCard
* MediaCarousel
* RatingControl
* StatusBadge
* ReviewCard
* ActivityCard
* UserAvatar
* EmptyState
* LoadingSkeleton
* Modal
* Button
* Input
* AdminMetricCard
* Dashboard charts
* NotificationItem
* ReportStatusBadge

Reglas:

* Cada componente importante debe tener variante mobile y desktop.
* No usar estilos genéricos sin criterio.
* No usar componentes shadcn sin personalizarlos.
* No abusar de gradientes.
* No abusar de glassmorphism.
* No llenar todo de sombras.
* No usar más de 2 tipografías.
* No sacrificar legibilidad por estética.
* No copiar literalmente interfaces existentes.

Checklist visual por fase:

1. ¿La pantalla tiene identidad propia?
2. ¿Funciona bien en mobile?
3. ¿Tiene buen contraste?
4. ¿Los posters tienen protagonismo?
5. ¿Los estados loading/error/empty están diseñados?
6. ¿La UI evita estética genérica?
7. ¿Los componentes son reutilizables?
8. ¿La navegación es clara?
9. ¿Hay consistencia en espaciado, colores y tipografía?
10. ¿La interfaz se siente como producto real?

Si una pantalla se ve genérica, debes rechazarla y proponer mejoras concretas.
